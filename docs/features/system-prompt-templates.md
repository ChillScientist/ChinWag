# System Prompt Templates

ChinWag lets you save any session's system prompt as a reusable template so you can quickly reapply it to future chats.

## Saving a template
1. Open the **Settings** sidebar for any chat session.
2. Enter or edit the system prompt text.
3. Click **Save current prompt** and optionally provide a template name.

Templates are stored locally in the browser, so they persist across sessions on the same device.

## Applying a template
- Locate the template inside the **Prompt Templates** list in the Settings sidebar.
- Click **Apply** to immediately replace the session's current system prompt with the template's content.

## Managing templates
- Templates are listed with their names and a preview of the prompt text.
- You can delete any custom template by clicking the trash icon. The default "Helpful Assistant" template cannot be removed.
